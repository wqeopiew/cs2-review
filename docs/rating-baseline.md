# 内置 Rating 与 RS 基础估算

本页说明保留的原版基础估算。程序当前默认使用[第三轮 RT 参数](rating-round3.md)；点击“使用原版基础估算”可切回本页版本。本机计算整体、T 和 CT 的 Rating 与 Round Swing，不依赖 AI、密钥或另行导入模型。原版显示“原版基础估算 / 未校准”，不是 HLTV 官方评分。

## 公开依据

- [2025-08-20 首次发布](https://www.hltv.org/news/42485/introducing-rating-30)及其[全图全枪人数胜率表](https://img-cdn.hltv.org/gallerypicture/OBWhD_euNz08Ruj0WF7r7v.png)：提供旧版的 5×5 人数局面形状。它不是所有地图、经济和下包局面的完整表。
- [2025-10-29 调整](https://www.hltv.org/news/43047/rating-30-adjustments-go-live)及其[组合权重图](https://img-cdn.hltv.org/gallerypicture/GRYfSzefrBtamefz0Joljd.png)：击杀 25%、伤害 15%、存活 15%、KAST 8%、多杀 4%、Swing 33%。这些是子评分的组合权重，不是原始 KPR/ADR 等数字直接相乘的权重。
- [2026-10-01 更新](https://www.hltv.org/news/45596/rating-30-receives-small-accuracy-improvements)及其[5v5 地图基准图](https://img-cdn.hltv.org/gallerypicture/jYfwg4C8bPgD2T-svvMfZz.png)：提供部分当前地图的买枪局锚点及炸弹 10/5 秒规则。Cache 的正文与图有不一致，本模型对 Cache 使用全局锚点。

公开数值只提供部分依据。完整官方胜率表、六项子评分的中心与尺度，以及若干贡献分配参数没有公开。

## 本软件选择的假设

概率使用旧全局人数表的 log-odds，加上当前 5v5 地图锚点偏移。未知地图使用全局 T 胜率 48.6%。再按冻结装备分层的双方强度比修正赔率；下包后按剩余时间层级将 CT 赔率乘以 0.03、0.15 或 0.5。装备分层、强度和下包倍数是自身选择，未由职业参考集拟合；并非完整官方 2026 表。已确认的无人存活边界、实际参与回合、可靠生命值、炸弹时钟及拆包例外仍由事实层核验。

模型的六项固定锚点依次为 `[0.65, 70, 0.35, 0.70, 0.25, 0]`，尺度为 `[0.65, 70, 0.35, 0.70, 0.25, 0.08]`。单位分别是经济修正击杀/回合、经济修正 HP 伤害/回合、经济加权存活、经济加权评分 KAST、多杀点/回合、Swing 概率/回合。它们是软件固定参考点，不是官方平均值或标准差，也不会按每场用户比赛重新调整至 1.00。

子评分为 `1 + (特征 − 锚点) / 尺度`，综合按上述公开权重求和，最低为 0。RS 将实际参与回合的估算事件贡献平均值乘 100，单位是百分点，可以为负。击杀、伤害、闪光、补枪的份额采用自身的 `[0.5, 0.3, 0.1, 0.1]`；回合末仍使用现有的正向击杀分配策略，尚未完整重建官方残局、拆包、存活类别分配。

## 可复现与缺失状态

内置模型版本为 `rating-baseline-v1`，模型文件格式为 schema 2。没有训练清单 SHA、观测计数、训练组或验证结果，不将公开概率冒充训练次数。参数、说明和模型版本共同生成 SHA；内置模型只接受当前发布参数，自训模型继续使用独立参考模型格式。公式或内置概率基础变动需要更新模型版本。

已导入的有效参考模型优先于内置模型。其需要的事实缺失时保持不可用，不静默换模型。已保存模型无法加载时明确提示回退；点击“恢复内置估算”才清除保存的选择。旧版模型的格式和 SHA 保持兼容。

没有可靠参与回合、必要装备/生命值/时钟未知、状态冲突或非有限计算时，Rating/RS 保持不可用并显示原因。本地 Demo 的可用性检查不能作为职业评分精度证据。

2026-10-13 完成首轮真实职业试校准：三组比赛、每组一张地图、30 个整体玩家结果，逐组留出并在折内重新训练。相同修复输入上的内置基线 Rating MAE 为 0.1220、RS MAE 为 1.0070 个百分点；实验模型分别为 0.1302、3.7273。实验模型整体变差，未替换内置基线。三组来自同一赛事、仅两种地图且选手重复，标签取自 2026-10-12 采集的官方索引文本；这些结果仅为探索性评估，不能证明正式校准或官方等价。事件与血量口径见 [原始统计说明](raw-statistics.md)。
