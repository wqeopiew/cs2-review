# 原始统计与评分的事件窗口

解析器 `cs2-review/2.1`、分析 `raw-v2/rules-v3` 分别保存胜负确定与统计结算证据。

- `EndedAt` 是实际 RoundEnd 的时间。Rating、RS、首杀、补枪、战术上下文及报告证据都在此截止。
- `StatisticsEndedAt` 只在同回合实际 RoundEndOfficial 被记录时设置。结算前的退场击杀、伤害和闪光可进入原始统计；缺少边界时保持空，排除尚未确认的退出事件。
- `AfterRoundEnd=true` 表示事件在 RoundEnd 之后按记录顺序收到。即使时间戳与 EndedAt 相同，也不能获得评分或作为战术报告证据；不人为移动事件时间。
- 进入下一回合、暖身、比赛重开或录制结束不会伪造统计结算。比赛结束后不继续接纳交火事件。最后一回合没有 RoundEndOfficial 时使用原胜负时间。

受伤事件保存服务器 `HealthDamage` 与可空 `TargetHealthAfter`。每次先用已知剩余 HP 封顶伤害，再同步该条受伤事件记录的剩余 HP；队伤、环境伤害也更新账本。合法受伤 HP 优先于可能陈旧的实体快照，确认死亡后不会被后续正值回调复活。缺字段的旧数据保留原回退口径。

这些字段是 schema 2 的可选扩展。新版程序继续读取旧 schema 1/2；新解析器需搭配新版程序使用。旧导入中已丢失的事件无法通过重新计算恢复，需重新导入原 Demo，历史按新的解析器版本保存。

本轮纠正已有实际 HP 和事件阶段定义的实现问题。内置模型的公式、概率锚点、权重和模型 ID 保持不变；模型对比统一使用修复后的事实与程序版本。原始 KAST 与评分 KAST 的本地定义保留，未为迎合官方显示值改写补枪规则。
